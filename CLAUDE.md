# FlyRank Capstone

## Stack

- **HTML** - semantic markup
- **CSS** - styling and layout
- **JavaScript** - client-side behavior
- **AI-assisted development** - Cursor and similar tools for iteration and scaffolding (to be extended as the project grows)

No build step or framework is assumed unless added later.

## Conventions

- Use clear, descriptive names for files, functions, and variables.
- Add comments only for non-obvious or complex logic; keep code self-explanatory where possible.
- Design mobile-first and ensure layouts work across screen sizes (responsive CSS, flexible units, readable touch targets).  
## AI Collaboration & Code Rules  
1. Always implement field-level validation (blur & submit events) with user-visible error feedback for forms.  
2. Include essential accessibility attributes (aria-describedby, aria-live, explicit label-input associations) by default.  
3. Validate API dependencies and active model identifiers before executing code generation pipelines.
